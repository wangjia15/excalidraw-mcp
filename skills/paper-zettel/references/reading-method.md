# 阅读方法：三遍法 × 卡片盒

基于 S. Keshav《How to Read a Paper》的三遍法，每一遍产出不同类型的卡片。

| 遍次 | 时间 | 读什么 | 产出 |
|---|---|---|---|
| 第一遍 鸟瞰 | 10 分钟 | 标题、摘要、引言、各级标题、结论、所有图表标题、参考文献扫一眼 | **文献笔记**（5C）+ 问题卡 |
| 第二遍 结构 | 1 小时 | 正文和图表细读，跳过证明细节；标出没看懂的地方和要追的引文 | 方法卡、实验卡、结果卡、概念卡 |
| 第三遍 重构 | 数小时 | 假装自己来写这篇论文：重推公式、检查假设、想反例、想下一步 | 推导卡、批判卡、启发卡、永久卡 |

## 第一遍：5C（写进文献笔记 `Papers/<KEY>/<KEY>.md`）

- **Category 类别**：哪类论文？（新架构 / 训练方法 / 数据集 / 基准测试 / 分析 / 系统 / 综述）
- **Context 背景**：接着哪几篇工作做的？用 `[[ ]]` 链到已有论文或永久卡。
- **Correctness 可信度**：关键假设看起来是否成立？
- **Contributions 贡献**：作者自称的贡献（1–3 条，原话加页码），以及我判断的真实贡献。
- **Clarity 清晰度**：写得是否清楚？哪里需要第二遍重点读？

第一遍结束时问自己：**值不值得读第二遍？** 不值得就只留文献笔记和 1–2 张卡，并告诉用户。

## 卡片类型

| 代码 | 类型 | 回答的问题 | 正面常用版式 |
|---|---|---|---|
| Q | 问题/动机 | 现有方法哪里不行？为什么重要？ | `vs`（旧 vs 新）、`callouts` |
| C | 概念 | 一个新术语/机制是什么？ | `kv`、草图 |
| M | 方法 | 怎么做的？模块、数据流、损失 | `flow`、草图、`code`（伪代码） |
| D | 推导 | 公式从哪来？为什么成立？ | 草图 + latex（apply） |
| E | 实验设置 | 数据、基线、指标、算力 | `kv`、table 式 bullets（`A → B`） |
| R | 结果 | 关键数字与结论（只放最有说服力的 1–3 个） | `kpis`、论文原图 `image` |
| A | 消融 | 哪个组件贡献了多少？ | table 式 bullets、`kpis` |
| K | 批判/局限 | 假设、漏洞、作者没说的代价 | `callouts`（warn/ask） |
| I | 启发 | 我能拿来做什么？和别的工作怎么连起来？ | `vs`、`callouts`（task） |

卡片 ID：`<KEY>-<代码><两位序号>`，如 `VIT-M02`。永久卡用 `Z-<主题>`，如 `Z-RoPE`。

## 第二、三遍精读清单 —— LLM 论文

逐项回答。论文没写的，在文献笔记的"未说明"列表里记一笔，不要猜。

- **模型**：架构（decoder-only / MoE / SSM / 混合）、层数/宽度/头数、参数量（总量/激活量）、上下文长度、位置编码、归一化、激活函数、tokenizer 与词表大小
- **数据**：规模（token 数）、来源配比、清洗/去重/过滤、合成数据、数据污染检查
- **训练**：目标函数、阶段（预训练 → 继续预训练 → SFT → RLHF/DPO/GRPO …）、优化器与学习率调度、batch、算力（GPU·时 / FLOPs）、稳定性技巧
- **对齐与推理**：奖励模型、偏好数据、思维链/推理时扩展、工具使用
- **评测**：基准（MMLU、GSM8K、MATH、HumanEval、MT-Bench、长上下文…）、few-shot 设置、对比基线是否公平（同算力、同数据）
- **效率**：推理成本、KV cache、量化、吞吐/延迟
- **扩展规律**：有没有 scaling 曲线？外推是否可信？
- **消融**：哪个改动真正带来了提升？
- **安全与局限**：幻觉、偏见、可复现性（权重/代码/数据是否公开）

## 第二、三遍精读清单 —— 视觉 / 多模态论文

- **任务**：分类 / 检测 / 分割 / 深度估计 / 生成 / 视频 / 3D / VLM
- **骨干**：CNN / ViT / 混合；patch 大小、输入分辨率、多尺度特征（FPN）
- **预训练**：监督、自监督（MAE/DINO）、对比学习（CLIP）、生成式预训练
- **头部与损失**：检测头、分配策略（匈牙利匹配 / NMS-free）、损失组成及权重
- **生成模型**：扩散/流匹配、噪声调度、条件注入（cross-attn / adaLN）、采样步数、CFG
- **VLM**：视觉编码器 → 连接器（MLP / Q-Former / 重采样器）→ LLM；分辨率策略（切图、动态分辨率）、对齐数据与训练阶段
- **数据与增强**：ImageNet / COCO / ADE20K / LAION …，增强方式、标注成本
- **指标**：top-1、AP/AP50、mIoU、FID/CLIPScore、VQA 准确率；FLOPs、参数量、FPS 及测速硬件
- **定性结果**：可视化图是否经过挑选？有没有给失败案例？
- **公平性**：和基线是否在相同训练轮数、分辨率、预训练数据下比较？

## 拆卡顺序（推荐）

1. Q 卡 1–2 张 → 2. M 卡（总体流程 1 张 + 每个关键模块 1 张）→ 3. C/D 卡（论文核心机制）→ 4. E/R/A 卡 → 5. K/I 卡 → 6. 从 C/D 卡里提炼永久卡 → 7. 思维导图。
