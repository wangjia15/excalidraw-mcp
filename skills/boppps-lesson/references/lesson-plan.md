# 教案模板（课件的 Markdown 面，`obsidian_write_slides` 的 `back` 参数）

规则：

- 可以用 `#`/`##` 标题（课件背面没有自动生成的分节）。
- 不能出现这些标题行：`# Excalidraw Data`、`## Text Elements`、`## Element Links`、`## Embedded Files`、`## Drawing`（工具会拒绝）。
- 教学过程表的"幻灯片"列写页码（与 PPT 页脚 `n / N` 一致，封面是第 1 页）。
- 时间合计必须等于课时，并与 PPT 分隔页 `badge` 一致。
- Mermaid 用 ```` ```mermaid ```` 代码块（背面原生渲染，不需要转换）。
