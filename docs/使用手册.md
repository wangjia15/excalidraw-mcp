# Excalidraw MCP · Obsidian 使用手册

让 AI 直接在 Obsidian 的 Excalidraw 里画图：写入/读取 `.excalidraw.md` 画板，一键生成**思维导图、幻灯片、11 种图表模板**，并针对**中文排版**做了优化。

> 本手册对应分支 `feat/obsidian-excalidraw-plugin`。除"已验证"标注外，生成结果的数据结构是对照插件和脚本源码实现的，请以你在 Obsidian 中的实际打开效果为准。

## 1. 能做什么

| 需求 | 用哪个工具 |
|---|---|
| 查看 / 读取 vault 里的画板 | `obsidian_list_drawings`、`obsidian_read_drawing` |
| 把任意 Excalidraw 元素写成画板 | `obsidian_write_drawing` |
| 分层架构、时间线、泳道、四象限、漏斗、流程图等 | `obsidian_write_template` |
| 思维导图（支持 Growth Strategy） | `obsidian_write_mindmap` |
| 幻灯片（配合 Slideshow 脚本放映） | `obsidian_write_slides` |
| 论文卡片盒：导图 + 图形化卡片 + 每卡背面 | `obsidian_write_paper_board` |
| 单张双面卡片（正面幻灯片、背面笔记） | `obsidian_write_card` |
| 聊天窗口里即时预览手绘图 | `create_view`（原有功能，不写入 vault） |

对 AI 说话即可，例如：

- “用分层架构模板画一张 Spring Cloud 微服务架构图，放到 `Excalidraw/架构图.excalidraw.md`”
- “把这份大纲做成 Right-Left 的思维导图”
- “基于这篇笔记生成 12 页的幻灯片，代码要高亮”

## 2. 安装与配置

### 2.1 构建

```bash
cd I:\app\excalidraw-mcp
git checkout feat/obsidian-excalidraw-plugin
npm install
npm run build        # 产物：dist/index.js
```

> 每次修改 `src/` 后需要重新 `npm run build`，并**重启 / 重连** MCP，客户端才会加载新工具。

### 2.2 指定 vault

所有 `obsidian_*` 工具通过环境变量 **`OBSIDIAN_VAULT`** 找到仓库，路径是 Obsidian vault 根目录（里面有 `.obsidian` 文件夹）。工具里的 `path` 都是**相对 vault 的路径**，并且不允许跳出 vault（`../` 会被拒绝）。

### 2.3 接入 Claude Code

```bash
claude mcp add -s user excalidraw -e OBSIDIAN_VAULT=I:/202609/course -- node I:/app/excalidraw-mcp/dist/index.js --stdio
claude mcp list        # 应显示 excalidraw ✔ Connected
```

> 注意参数顺序：服务器名 `excalidraw` 放在 `-e` 前面。

### 2.4 接入 omp

编辑 `~/.omp/agent/mcp.json`（`$schema` 必须有）：

```json
{
  "$schema": "https://raw.githubusercontent.com/can1357/oh-my-pi/main/packages/coding-agent/src/config/mcp-schema.json",
  "mcpServers": {
    "excalidraw": {
      "type": "stdio",
      "command": "node",
      "args": ["I:/app/excalidraw-mcp/dist/index.js", "--stdio"],
      "env": { "OBSIDIAN_VAULT": "I:/202609/course" }
    }
  }
}
```

### 2.5 Claude Desktop

```json
{
  "excalidraw": {
    "command": "node",
    "args": ["I:/app/excalidraw-mcp/dist/index.js", "--stdio"],
    "env": { "OBSIDIAN_VAULT": "I:/202609/course" }
  }
}
```

### 2.6 可选：把 Excalidraw 渲染引擎换成插件自带的 fork

`create_view` 的聊天内预览默认从 esm.sh 加载官方 Excalidraw。构建时设置 `EXCALIDRAW_LIB` 可改用本地包（例如插件仓库安装依赖后的 `@zsviczian/excalidraw`）：

```bash
EXCALIDRAW_LIB=I:/app/obsidian-excalidraw-plugin/node_modules/@zsviczian/excalidraw npm run build
```

> 该路径未实际验证；插件仓库需要先 `npm install`。

## 3. 工具总览

列出 vault 里所有 `.excalidraw.md`。

| 参数 | 说明 |
|---|---|
| `dir` | 可选，相对 vault 的子目录 |

### 3.2 `obsidian_read_drawing`

读取画板，返回**未删除元素**的 JSON 数组（可直接作为 `create_view` 的输入）。

| 参数 | 说明 |
|---|---|
| `path` | 以 `.excalidraw.md` 结尾 |

### 3.3 `obsidian_write_drawing`

把一组标准 Excalidraw 元素写成画板。覆盖已有画板时保留原有 frontmatter、appState 与图片文件。

| 参数 | 说明 |
|---|---|
| `path` | 以 `.excalidraw.md` 结尾 |
| `elements` | 元素数组的 JSON 字符串 |
| `overwrite` | 默认 `false`；文件已存在时必须设为 `true` |
| `style` | `"professional"`（默认）或 `"none"` |

**默认专业模板（`style: "professional"`）**：对没写的属性补默认值——`roughness: 0`（不手绘抖动）、`strokeWidth: 1.5`、文字 `fontFamily: 2`（Helvetica，中文回退系统字体），并在 `appState` 里写入同样的 `currentItem*` 默认值，之后你手动画的图形也沿用这套风格。元素上显式写了的属性不会被覆盖。

写入时会自动把元素 id 改成 **8 位字母数字**（见 [常见问题](#9-常见问题) 第 1 条）。

### 3.4 `obsidian_write_template` / `obsidian_template_help`

### 3.5 `obsidian_write_mindmap`

### 3.6 `obsidian_write_slides`

见第 6 节；`mermaid` 字段见第 13 节。

## 4. 图表模板（11 种）

调用方式：

```
obsidian_write_template
  path:  Excalidraw/xxx.excalidraw.md
  kind:  layers | timeline | compare | table | tree | swimlane | quadrant | funnel | cycle | cards | flow
  spec:  JSON 字符串（见下）
  font:  sans（默认）| hand
  overwrite: true/false
```

所有模板的 `spec` 都可带 `title`（标题）和 `subtitle`（副标题）。每种模板的示例成品已生成在 vault 的 **`Excalidraw/模板示例/`** 目录，可直接打开参考。

| kind | 用途 | spec 核心字段 |
|---|---|---|
| `layers` | 分层架构图 | `layers:[{name, items:[文本]}]` |
| `timeline` | 时间线（上下交错） | `events:[{time, title, desc?}]` |
| `compare` | 左右对比 + VS | `left:{title,items}`、`right:{title,items}` |
| `table` | 表头 + 斑马纹表格 | `columns:[…]`、`rows:[[…]]` |
| `tree` | 树状图 / 组织结构 | `root:{t, c?:[{t,c?}]}` |
| `swimlane` | 泳道流程图 | `lanes:[…]`、`steps:[{lane, text, decision?}]` |
| `quadrant` | 四象限 | `xAxis:[低,高]`、`yAxis:[低,高]`、`quadrants:[左上,右上,左下,右下]`、`items:[{text,x:0~1,y:0~1}]` |
| `funnel` | 漏斗 / 金字塔 | `levels:[{text,note?}]`、`shape?:"funnel"\|"pyramid"` |
| `cycle` | 环形循环 | `steps:[…]`（≥3）、`center?` |
| `cards` | 编号要点卡片 | `cards:[{title, body?}]`、`columns?` |
| `flow` | 流程图（自动蛇形换行） | `steps:[文本 \| {text, type?}]`、`columns?` |

`flow` 的 `type` 可取 `start` / `end` / `process` / `decision`：开始、结束画成椭圆，判断画成菱形；只给字符串时，第一个当开始、最后一个当结束。

### 示例：分层架构

```json
{
  "title": "Spring Cloud 微服务分层架构",
  "subtitle": "从接入到数据，每层职责清晰",
  "layers": [
    {"name": "接入层", "items": ["Nginx 负载均衡", "Spring Cloud Gateway", "Sentinel 限流"]},
    {"name": "业务服务层", "items": ["用户服务", "订单服务", "商品服务", "支付服务"]},
    {"name": "数据层", "items": ["MySQL 主从", "Redis 集群", "RabbitMQ"]}
  ]
}
```

### 示例：泳道流程

```json
{
  "title": "下单流程泳道图",
  "lanes": ["用户", "订单服务", "库存服务", "支付服务"],
  "steps": [
    {"lane": "用户", "text": "提交订单"},
    {"lane": "订单服务", "text": "创建订单"},
    {"lane": "库存服务", "text": "库存充足？", "decision": true},
    {"lane": "支付服务", "text": "发起支付"}
  ]
}
```

### 示例：四象限

```json
{
  "title": "技术选型四象限",
  "xAxis": ["成本低", "成本高"],
  "yAxis": ["价值低", "价值高"],
  "quadrants": ["快速收益", "战略投入", "谨慎评估", "可以放弃"],
  "items": [{"text": "Nacos", "x": 0.25, "y": 0.8}, {"text": "Seata", "x": 0.75, "y": 0.75}]
}
```

### 模板的共同特点

- 形状里的文字是**绑定文字**（`containerId`），在 Obsidian 里拖动 / 缩放形状，文字会跟着居中。
- 箭头两端绑定到形状（拖动形状，箭头跟随）。
- 配色统一为一套柔和色板（绿 / 蓝 / 橙 / 紫 / 红 / 青），线条无抖动，适合直接放进文档或课件。
- 形状会根据文字**自动撑高**，长句不会溢出。

## 5. 思维导图（Mind Map Builder）

```
obsidian_write_mindmap
  path:       Excalidraw/xxx.excalidraw.md
  outline:    缩进大纲（第一行是根节点）
  growthMode: Radial | Right-facing | Left-facing | Right-Left（默认）| Up-facing | Down-facing | Up-Down
  overwrite:  true/false
```

### 大纲写法

用两个空格或一个 Tab 缩进；行首的 `- `、`* `、`# ` 会被去掉：

```
Spring Cloud 微服务
- 服务注册与发现
  - Nacos
    - 服务注册 / 心跳
  - Eureka / Consul
- API 网关
  - Spring Cloud Gateway
```

### XMind 风格与 Slideshow 播放

- **外观**（参考 XMind 的彩色分支）：根节点是深色胶囊；一级主题是实心圆角色块（白字）；二级主题是浅色圆角块 + 同色边框；三级及以下是"文字 + 下划线"；分支线是随层级变细的平滑曲线，每个一级分支一种颜色。
- **左右均衡**：`Right-Left` 按各分支的**实际高度**（含图片）分配左右两侧，而不是按个数。
- **Slideshow 帧**（默认开启，`frames: false` 可关闭）：自动加入**标记 frame**，让整张导图能用 Slideshow 脚本播放：
  - 第 0 帧是**全图概览**；
  - 之后每个一级分支一帧；分支太长时按二级主题自动拆成多帧（`frameHeight` 控制一屏容纳的内容高度，默认 760），名称形如 `04 方法 (2/3)`；
  - 每帧都是 **16:9**，并按内容居中、留白，宽度不小于 1280，保证一屏看得清；
  - 演讲者备注自动写入该帧覆盖的大纲要点。
  - 这些 frame 是"标记 frame"：不包含元素、不裁剪内容（`frameRendering.clip = false`），拖动导图节点不会受影响。
- **字体**：`font` 参数——`sans`（默认，Helvetica → 系统 UI 字体，中文回退微软雅黑 / 苹方，与 Obsidian 默认的系统文本字体一致）、`hand`（Excalifont）、`local`（Excalidraw 插件设置里的 **Local Font**）。Excalidraw 无法直接引用 Obsidian 的 `--font-text` 变量；如果你在 Obsidian 外观里设置了自定义**文本字体**，想让导图一致，请把同一个字体文件设为插件的 Local Font，再传 `font: "local"`。

### 图片节点与主题

- **图片节点**：大纲里写 `![说明](相对 vault 的路径)`，就会生成一个嵌入图片的节点（支持 PNG / JPEG / GIF / WebP，尺寸从文件读取）。图片文件需要在 vault 里；文件以 `## Embedded Files` 的形式记录在画板中。
- **读图解读**：把解读要点写成图片节点的**同级兄弟节点**（或放在一个标题节点下，与图片并列），例如：

```
图 2　整体框架
  - ![图2 整体框架图](Excalidraw/YOLO-Master/fig2.png)
  - 上方主干：输入 → Backbone → Neck → Head → 输出
  - 左下展开 ES-MoE：路由 → 门控 → 专家 → Top-K → 加权聚合
```

- **`theme`**：`campus` 等 Marp 主题名，决定分支配色、根节点配色和画布背景。一级分支文字用分支色，下层文字用正文墨色，保证可读。
- **`maxWidth`**（默认 460）：节点文字换行宽度；**`imageWidth`**（默认 640）：图片节点显示宽度。
- 示例成品：`Excalidraw/YOLO-Master/YOLO-Master 论文思维导图.excalidraw.md`（对 arXiv 2512.23273 的中文导读，含 4 张图及解读）。

### Growth Strategy（生长方向）

| 值 | 布局 |
|---|---|
| `Right-Left` | 一级分支前一半在右、后一半在左（默认） |
| `Right-facing` / `Left-facing` | 全部向右 / 全部向左 |
| `Down-facing` / `Up-facing` | 子节点在下方 / 上方横向展开 |
| `Up-Down` | 一半在下、一半在上 |
| `Radial` | 从正上方起顺时针围成椭圆 |

所选策略会写在根节点的 `customData.growthMode`。生成的数据结构与 Mind Map Builder 脚本一致：节点带 `mindmapOrder`，分支线是带 `isBranch` 标记的绑定弯曲线，每个一级分支一种颜色，层级越深字越小、线越细。

在 Obsidian 里打开后，启动 **Mind Map Builder** 脚本，选中根节点即可用它自己的引擎重排、切换 Growth Strategy、折叠 / 展开分支。

## 6. 幻灯片（Slideshow）

```
obsidian_write_slides
  path:      Excalidraw/xxx.excalidraw.md
  deck:      JSON 字符串
  overwrite: true/false
```

### deck 结构

```json
{
  "title": "第02讲 Web 开发与 RESTful API",
  "slides": [
    { "title": "Web 开发与 RESTful API", "subtitle": "Spring Boot 4 系列 · 第 2 讲" },
    { "title": "1 请求处理完整流程", "flow": ["① 请求 → DispatcherServlet", "② 查找 HandlerMapping"], "notes": "演讲备注" },
    { "title": "2 参数绑定", "bullets": ["@PathVariable：指定资源", "@RequestParam：筛选分页"] },
    { "title": "3 统一响应", "bullets": ["要点 1", "要点 2"], "code": "public class Result<T> { }", "codeTitle": "Result.java" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `title` | 标题。**开头的数字**（如 `3 统一响应`）会变成圆形章节徽章 |
| `subtitle` | 副标题，渲染为浅绿提示条 |
| `bullets` | 要点数组，**自动选择版式**（见下） |
| `code` / `codeTitle` / `codeLang` | 代码及窗口标题；语言自动识别，可用 `codeLang` 指定 |
| `flow` | 流程项数组，画成带编号的流程图 |
| `notes` | 演讲者备注，写入 frame 的 `customData.slideshow.notes` |
| `layout` | 强制要点版式：`list` / `cards` / `steps` / `table` |
| `animate` | `false` 则不逐条淡入（默认逐条） |

### 版式自动选择

- **第一页** = 封面（深色背景）。
- **没有任何内容的页**（无要点 / 代码 / 流程）= 章节分隔页。
- 要点的版式由内容决定：
  - 多数行含 **`标题：说明`**（中文冒号）→ **编号卡片**；
  - 多数行以 `①②③` 或 `1.` 开头 → **编号步骤**；
  - 每行都含 `→` → **表格**（`GET`/`POST`/`PUT`/`PATCH`/`DELETE` 变成彩色标签，`200`/`404` 等状态码按 2xx/4xx/5xx 着色）；
  - 其余 → **带彩条的行卡片**。
- 一行里用 3 个以上空格并排的多个 `A：x    B：y` 会自动拆成多条。
- 流程项里的 `→` 会换行；`①`~`⑩` 会变成编号圆标；流程过长时自动按**蛇形**多行排列，文字尽量不被拆断。
- 有要点又有代码时，左侧要点 / 右侧代码；空间不够会改为上下排布。

### 6.1 主题（Marp 主题 → Excalidraw）

`obsidian_write_slides` 的 `theme` 参数可以直接套用 vault 里的 **Marp 主题 CSS**，让 Excalidraw 幻灯片和你的 Marp 课件长得一样：

| theme | 来源 | 风格 |
|---|---|---|
| `fresh`（默认） | 内置 | 绿色清爽 |
| `campus` | `<vault>/theme/campus.css` | 学院藏青金：藏青封面 + 上下金线，居中封面与环节分隔页，金色细下划线 |
| `campus43` | `theme/campus43.css` | 同上，4:3（1920×1440） |
| `blackboard` | `theme/blackboard.css` | 黑板绿底 + 粉笔黄；代码用浅色"贴纸"配浅色高亮 |
| `ink` | `theme/ink.css` | 宣纸米色 + 朱砂红 |
| `swiss` | `theme/swiss.css` | 瑞士红黑白 |
| 其他 | `theme/<名字>.css` 或 CSS 绝对路径 | 只要 `:root` 里有 `--bg`、`--accent` 等变量即可 |

读取的内容：`:root` 里的配色变量（`--bg --soft --ink --ink2 --ink3 --line --accent --alt --code-bg --tip/warn/task/ask-bg|bd --c-b --c-o --c-p1 --c-p2 --c-p3 --c-s`）和 `section` 的宽高（×1.5 换算成 Excalidraw 尺寸）。名字含 `campus` 的主题使用"正装"版式（深色封面、居中、金线）。

已生成五套主题的完整示范稿：`Excalidraw/幻灯片主题模板/{campus,campus43,blackboard,ink,swiss}.excalidraw.md`（同一份 12 页 BOPPPS 教学稿，方便对比）。

**字体**：`deck.titleFont` / `deck.bodyFont` 可选 `sans`（默认，系统中文黑体）、`hand`（Excalifont）、`local`（Excalidraw 插件设置里的"Local Font"）。想要 campus.css 那种**宋体标题**或**霞鹜文楷正文**：把字体文件放进 vault，在插件设置的 Local Font 里指定，再设 `"titleFont":"local"`（或 `bodyFont`）。未配置 Local Font 时请不要选 `local`。

### 6.2 BOPPPS 教学元素

在每页上增加这些字段即可（对应 campus.css 的 BOPPPS 教学层）：

| 字段 | 效果 |
|---|---|
| `stage`: `b`/`o`/`p1`/`p2`/`p3`/`s` | 页面右上角**六点进度条** B·O·P·P·P·S，点亮当前环节；环节分隔页用环节色 |
| `type`: `"stage"` / `"divider"` | 环节 / 章节分隔页（没有任何内容的页会自动成为分隔页） |
| `badge`: `"5 分钟"` | 标题旁的时长胶囊 |
| `act`: `"动手实践"` | 标题旁的学生动作胶囊 |
| `callouts`: `[{kind, text}]` | 底部提示条，`kind` 为 `tip`（提示）`warn`（注意）`task`（任务）`ask`（思考） |
| `kpis`: `[{num, label}]` | 大数字指标卡 |
| `vs`: `{left:{title,items}, right:{...}}` | 左右对比 + VS 徽章 |
| `kv`: `[[键, 值], …]` | 键值对网格 |
| `image`: `{path, caption?}` | 插入 vault 里的图片（PNG/JPEG/GIF/WebP）：宽图放在要点上方，其余放左侧、要点放右侧；图片以文件链接的方式嵌入画板 |

示例：

```json
{
  "title": "Spring Cloud 微服务入门",
  "slides": [
    { "title": "Spring Cloud 微服务入门", "subtitle": "BOPPPS 教学模式 · 45 分钟示范课" },
    { "type": "stage", "stage": "b", "title": "导入 Bridge-in", "badge": "5 分钟" },
    { "title": "为什么需要微服务？", "stage": "b",
      "kpis": [{"num": "10x", "label": "大促订单量峰值"}],
      "callouts": [{"kind": "ask", "text": "支付模块故障，整个商城都要下线吗？"}] }
  ]
}
```
调用时加上 `theme: "campus"`。

### 代码高亮

内置 One Dark 配色，支持 **Java / TS / Vue / YAML / JSON / HTTP / Shell / XML**。因为 Excalidraw 文字只能单色，做法是按颜色拆成多层文字、层层叠放（非本层的字符用空格占位），所以：

- 一个代码窗口里会有多个文字元素；
- 想改代码，建议改源文件后重新生成，而不是在画板里逐字编辑。

### 放映

在 Obsidian 里打开该画板，运行 **Slideshow** 脚本：

- 直接点击：全屏放映；`Alt/Option` + 点击：窗口放映；`Ctrl/Cmd` + 点击：打开侧栏编辑。
- 翻页：`→` / `↓` / 空格 前进，`←` / `↑` 后退，`Esc` 或 `Backspace` 结束。
- 页序、备注、动画都读自每个 frame 的 `customData.slideshow`；要点按"前进键一次出现一条"的方式淡入。

## 7. 中文排版与字体

### 7.1 字体选择

| `font` | Excalidraw fontFamily | 效果 |
|---|---|---|
| `sans`（默认） | 2 = Helvetica | 英文 Helvetica，**中文回退系统 UI 字体**（Windows 微软雅黑 / macOS 苹方），整洁专业 |
| `hand` | 5 = Excalifont | 手绘风。英文用手写体；中文在插件设置 **Load Chinese fonts** 开启后使用小赖手写字体，否则回退系统字体 |
| 代码 | 3 = Cascadia | 等宽字体，中文注释回退系统字体 |

建议：**课件、架构图、文档用 `sans`**；想要白板手绘感再用 `hand`，并在 Obsidian 的 Excalidraw 插件设置里开启 *Load Chinese fonts*。

### 7.2 已做的中文优化

- **宽度按字符计算**：汉字、全角标点按 1em 宽，英文约 0.56em，代码等宽字体约 0.6em，因此框、卡片、表格列宽都能贴合中英混排的文字。
- **行高 1.3**（模板）：比英文默认值更透气，汉字不挤；幻灯片按各自版式取值。
- **禁则处理**：换行时 `，。、；：！？）》」』”’…` 不会出现在行首，`（《「『“‘` 不会停在行尾；英文单词、标识符（如 `HandlerExecutionChain`）不会被从中间断开，除非单词本身比框还宽。
- **字号自适应**：卡片标题、流程框会根据最长的"不可拆分片段"自动缩小字号，避免出现 `DispatcherServle / t` 这种折断。
- **形状自动撑高**：文字换行后超出的高度会撑开形状，而不是溢出。
- **代码高亮的中文注释**：占位用全角空格，保证叠层对齐。

### 7.3 写作建议

- 卡片 / 要点用**中文冒号 `：`** 分隔标题和说明，才能触发卡片版式。
- 标签尽量精炼（节点 ≤ 12 字，卡片标题 ≤ 24 字）。
- 中英文之间留一个空格更易读（如 `Nacos 注册中心`）。
- 避免在文字里使用 emoji（Excalidraw 字体不渲染）。

## 9. 常见问题

**1. 打开后所有文字都是空的？**
Excalidraw 插件只会从文件的 `## Text Elements` 段里读取 **8 位字母 / 数字 / `_` / `-`** 的元素 id 对应的文字；其他长度的 id 加载后文字会变成空串，再保存就永久丢失。本工具写入时已经自动把 id 改成 8 位，你**自己手写元素**时也无需操心；如果用其他方式写入，请自行保证 id 是 8 位。

**2. 重启后看不到新工具？**
修改后要 `npm run build`，再重启会话（或在 `/mcp` 里重连）。omp 同理。

**3. 报 `OBSIDIAN_VAULT environment variable is not set`？**
MCP 配置里没有 `env.OBSIDIAN_VAULT`，见第 2 节。

**4. 报 `... already exists (pass overwrite: true)`？**
目标文件已存在，需要显式 `overwrite: true`。

**5. 报 `Path escapes the vault`？**
路径跳出了 vault，请使用相对 vault 的路径。

**6. 中文显示成方框 / 字体不一致？**
`sans` 依赖系统字体，通常无需处理；`hand` 想要中文手写效果，需在插件设置里开启 *Load Chinese fonts*。

**7. Mind Map Builder 不识别 / 排版不对？**
先用脚本的"重新排布"动作重排一次。若脚本版本和本工具假设的数据结构不一致，请反馈具体表现。

**8. 幻灯片里代码对不齐？**
对齐依赖等宽字体的字宽估算（Cascadia ≈ 0.6em）。若你的 Obsidian 使用了别的等宽字体，轻微错位属正常；反复出现请告知。

## 11. 双面画板：Markdown 面与 frontmatter

所有写工具（`obsidian_write_drawing`、`_template`、`_mindmap`、`_slides`、`_paper_board`、`_card`）都支持：

| 参数 | 说明 |
|---|---|
| `back` | 写在 `# Excalidraw Data` 上方的 Markdown，即画板的"背面"（命令面板 `Excalidraw: Toggle between Excalidraw and Markdown mode` 翻面）。可用 Mermaid、callout、`[[链接]]`、`![[嵌入]]` |
| `properties` | frontmatter 的 JSON 对象，如 `{"tags":["boppps"],"lesson":5}`；`excalidraw-plugin: parsed` 会自动加上 |

- 覆盖（`overwrite: true`）时省略 `back` / `properties`，会保留文件里原有的内容。
- 背面不能出现 `# Excalidraw Data`、`## Text Elements`、`## Element Links`、`## Embedded Files`、`## Drawing` 这些标题行，工具会拒绝写入。
- `obsidian_read_drawing` 传 `withBack: true` 返回 `{frontmatter, back, elements}`。

## 12. 论文卡片盒（paper board / card）

`obsidian_write_paper_board` 把一篇论文写成**一个画板**：思维导图的叶子就是 16:9 卡片（分支线直接连到卡片），Slideshow 先放全图概览，再按导图顺序逐张放卡片；Markdown 面是 `back` 里的文献笔记，后面自动接 `## 卡片` 和每张卡一节（`### <ID> <标题>` + 该卡帧的嵌入 + 卡片的 `back`）。点卡片背景会跳到它的那一节。

| 参数 | 说明 |
|---|---|
| `path` | 如 `Papers/VIT/VIT 卡片盒.excalidraw.md` |
| `board` | `{key, title, series, outline, cards, growthMode?, cardScale?}` 的 JSON 字符串 |
| `back` / `properties` | 见第 11 节 |
| `theme` / `font` | 同幻灯片主题；`sans`（默认）/ `hand` / `local` |

- `outline`：缩进大纲，第一行是根；`@<卡片ID>` 放一张卡，`[[笔记|别名]]` 是链接节点，其余是文字节点。没放进大纲的卡会归到"其他"分支。
- 卡片 `{id, title, visual, points?, takeaway?, source?, notes?, back?}`。`id` 的类型字母决定颜色：Q 问题、C 概念、M 方法、D 推导、E 实验、R 结果、A 消融、K 批判、I 启发、Z 永久卡。
- `visual` 是一个图形或两个图形的数组（自动选择并排/上下）：

| kind | 用途 | 写法 |
|---|---|---|
| `figure` | 论文原图 + 标注 | `{path, boxes:[{n,x,y,w,h}], marks:[{n,x,y}]}`，坐标是图片宽高的 0..1 比例；`n` 与 `points` 的编号对应时编号圈变红 |
| `tensor` | 张量形状变化 | `{steps:[{label,dims,op?}]}` |
| `matrix` | 注意力 / 相似度矩阵 | `{pattern:"causal"\|"diagonal"\|"local"\|"full", size}` 或 `{rows, cols, values, showValues}` |
| `stack` | 模块堆叠与残差 | `{layers:[{label,kind}], residual:[[i,j]], repeat}`，从下往上 |
| `patches` | 切 patch / token 化 | `{rows, cols, cls, label}` |
| `bars` | 数值对比 | `{title, unit, items:[{label,value,hl?}]}` |
| `template` | 任意模板图 | `{template:"compare", spec:{…}}`，spec 同 `obsidian_write_template` |
| `sketch` | 手绘元素 | `{elements:[…]}` |

完整示例：[examples/paper-board.json](examples/paper-board.json)。

`obsidian_write_card` 写**单张**双面卡片：`card` 是一页幻灯片的 JSON，`back` 是背面，`cardId` 显示在页脚，`sketch` 是画在卡片右侧的手绘元素数组。适合跨论文的"永久卡"。

## 13. 幻灯片中的 Mermaid 图与配套技能

### 13.1 `mermaid` 字段

```json
{ "stage": "p2", "title": "1 DispatcherServlet 统一分发请求",
  "mermaid": { "code": "flowchart LR\n  A[浏览器] --> B[DispatcherServlet]\n  B --> C{HandlerMapping}\n  C --> D[Controller]", "caption": "一次请求的路径" },
  "bullets": ["前端控制器：所有请求先到这里"] }
```

- 也可以直接写字符串 `"mermaid": "flowchart LR\n ..."`；`ratio`（宽/高）一般不用填（LR 2.4、TD 1.1、sequence 1.5、其他 1.6）。
- MCP 只能写出**占位框**（虚线框，代码存在 `customData.mermaid`，当前主题的配色和字体存在 `customData.mermaidStyle`）。转换由 vault 脚本 [`Mermaid to Excalidraw`](../skills/boppps-lesson/scripts/Mermaid%20to%20Excalidraw.md) 在 Obsidian 里调用插件内置的 mermaid-to-excalidraw 完成：
  - 把脚本复制到 vault 的 `Excalidraw/Scripts/`；
  - 在命令面板运行，或用插件 CLI：

```sh
obsidian vault=<vault> obsidian-excalidraw-plugin:open path="<课件>.excalidraw.md"
obsidian vault=<vault> obsidian-excalidraw-plugin:script path="<课件>.excalidraw.md" \
  script="Excalidraw/Scripts/Mermaid to Excalidraw.md" trusted=true requestId=mmd-1
```

- 脚本把图缩放到占位框内，去掉手绘效果、换成课件字体，并按主题上色：普通节点、判断（菱形）、圆形、分组（subgraph）、时序图参与者、连线和文字各取主题里的一种颜色。标签放不下时先略缩字号，再加宽形状并把左右节点推开。
- 返回 `{summary, report:[{id, ok, scale, minFont}]}`；`minFont` < 16 说明图上的字在 1920 宽的页面上偏小，改成 `TD`、减少节点或拆页。
- 可选 `args`：`{"style":{"decision":{"fill":"#fdf3dc","stroke":"#b8923f"},"line":"#35495e"}}` 覆盖部分配色；`{"theme":false}` 保留 Mermaid 原色；`{"sketch":true}` 保留手绘风格；`{"maxScale":1.8,"fontSize":20}`。
- MCP `overwrite` 重写后占位框会回来，需要再跑一次脚本。
- `flowchart`、`sequenceDiagram`、`classDiagram` 转成可编辑元素；其他类型插件会转成图片。

完整课件示例（BOPPPS、代码、Mermaid、VS、flow）：[examples/boppps-deck.json](examples/boppps-deck.json)，调用时加 `theme: "campus"`。
